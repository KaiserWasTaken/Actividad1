# Actividad 1 - Programación Web

## Descripción
Este proyecto contiene una serie de ejercicios prácticos de HTML y CSS desarrollados como parte de la actividad de programación web. La finalidad es reforzar el uso de etiquetas, estructura de documentos, diseño visual, enlaces, formularios, tablas y elementos interactivos básicos.

El proyecto se presenta a través de una página principal llamada `index.html`, desde la cual se accede a cada ejercicio individual.

## Objetivo de la actividad
Aprender y practicar los fundamentos del desarrollo web front-end mediante:

- Estructura correcta de documentos HTML
- Uso de títulos, párrafos, listas y enlaces
- Integración de imágenes y contenido multimedia
- Organización de secciones y diseño básico con CSS
- Creación de formularios y páginas de contacto
- Desarrollo de pequeñas aplicaciones web con lógica simple

## Estructura del proyecto

- `index.html` — página principal con acceso a todas las actividades
- `ejercicio1.html` hasta `ejercicio14.html` — ejercicios individuales
- `css/` — estilos utilizados por algunos ejercicios
- `img/` — recursos gráficos del proyecto

## Ejercicios incluidos

1. `ejercicio1.html` — presentación básica con “Hola Mundo”
2. `ejercicio2.html` — primera página con formato y estilo visual
3. `ejercicio3.html` — práctica con enlaces y navegación
4. `ejercicio4.html` — uso de imágenes y contenido visual
5. `ejercicio5.html` — creación de un blog personal
6. `ejercicio6.html` — organización por secciones de una página web
7. `ejercicio7.html` — receta de tacos al pastor
8. `ejercicio8.html` — horario escolar con diseño de tabla
9. `ejercicio9.html` — formulario o página de contacto
10. `ejercicio10.html` — calculadora de temperatura en Fahrenheit
11. `ejercicio11.html` — conversor de kilómetros a millas
12. `ejercicio12.html` — conversor de divisas MXN a USD
13. `ejercicio13.html` — validación de edad para votar
14. `ejercicio14.html` — calculadora de MMM

## Cómo visualizar el proyecto
1. Abre la carpeta del proyecto en tu navegador.
2. Ejecuta `index.html`.
3. Selecciona cualquiera de las actividades para ver cada ejercicio.
